## 独立审查处置

审查者只读，不修改实现。设计审查与实现审查发现的问题均先明确契约再修改实现，并添加症状回归。

| 发现 | 根治与验证 |
| --- | --- |
| 外围重复或试装声明校验 | core公开纯validatePlugin，application与装配共用真实token身份及声明校验 |
| 永久后台循环会碰执行期限 | timer每次创建有限任务，等待实际finished后再调度，关闭等待实际工作与子工作 |
| 应用失败替换快照仍报active | 快照依据真实实例与激活失败记录，覆盖迟到排空后恢复 |
| 定时辅助对象的匿名监听保留调度器 | helper不登记匿名宿主监听，实际schedule资源负责监听与释放；活跃宿主GC回归 |
| 保存作者Context/依赖门面保留token | 原始能力统一登记派生撤销，清空Context、声明、token和已取得服务；保留公开句柄的GC回归 |
| 关闭视图保留内部账本读端口 | finishClose清空元数据并替换读取端口，关闭视图不能保留或查询旧账本 |
| 脚手架检查后删除会误删并发替换文件 | 移除自动unlink/rmdir，失败保留未完成目录并返回directory；竞争文件和目录回归 |
| 多份加载器绕过导入预算 | 不可替换进程Symbol端口共享64次预算，源码及构建副本同进程原生旅程验证 |
| import.meta或计算式require绕过稳定身份 | Acorn产物分析仅允许直接url/main读取；解构、反射、动态属性和剩余动态导入拒绝；独立createRequire复现验证 |
| 失败构建未监听新依赖目录 | 构建阶段发现目录，失败仍同步监听，新增监听后再次验证；原生修复旅程 |
| 已删除依赖目录阻塞后续刷新 | 清除过期私有目录，根目录缺失时监听最近祖先，以设备及inode识别同路径替换 |
| 激活失败或多入口后续失败丢失准备缓存 | 成功导入逐入口保存，全部准备成功才发布；复现计数2→3→3→4，重复失败保留旧实例，修复后仅导入必要模块 |
| 初始失败关闭未收敛被隐藏 | 初始化返回restart-required，迟到取得资源仍关闭；加载期间close不能迟到发布 |

最后一轮独立复核确认多入口重试计数、旧实例保留、修复后复用及关闭竞态通过，无确认阻塞。

## 运行边界

loader仅接受可信模块，不能隔离同步死循环或未登记顶层副作用。进程导入预算64、共享目录变化或顶层await超期要求外部监督重启。热更新按依赖停止并排空后重新装配，不承诺请求零中断。配置持久化、业务恢复、可靠投递与进程监督属于外部插件或部署系统。

脚手架面向本地SDK；生成失败保留未完成目录，调用者以Result.ok判断完成。未执行远端发布包安装认证、60分钟持续运行、多轮延迟分位基准或分布式故障恢复，不宣称与其他框架全功能等价或性能最优。
