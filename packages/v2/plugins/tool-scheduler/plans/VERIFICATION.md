# Tool scheduler 测试口径

状态：已核销；实现之前定义。

- execute：等待与immediate、总/每工具限额、不同工具不头阻塞，tools busy不重试。
- batch：输入顺序结果、批内并发、DAG并行与先后、循环/悬空/重复整批零执行、失败及isError只阻止后代。
- 公平：origin lane轮转，优先级不越调用者，不同scope隔离，同lane优先级及最多3次后最老任务；已满工具不阻塞其他工具。
- 权限：默认拒绝、显式allow、deny优先、排队调用者真实origin、执行scheduler身份、工具新鲜授权、直接调用不能伪造origin。
- 生命周期：排队取消、运行取消、整体期限含排队、节点期限始于执行、卸载/关闭排空；非合作作者早回执但继续占全局/工具/批容量。
- 边界：所有数字上限、N-1/N/N+1、原子整批准入、垃圾/Proxy/getter/环输入、不修改用户对象、结果累计预算。
- progress：callId正确，慢消费者背压，失败/取消、保存结束回调不保留服务与调用。
- 核销：类型负例和完整README示例、真实HTTP构建混装及进程退出、四门与覆盖率、突变以AssertionError检出、独立假绿检查。
