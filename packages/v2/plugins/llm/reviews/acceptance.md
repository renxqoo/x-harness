## 契约与旅程

三协议均经生产 fetch 路径连接真实回环 HTTP：请求认证与参数、文本、图片输入、工具分片与完成、推理/签名/续接、JSON/schema、引用、usage、协议中断、早退和取消。构建入口在新进程运行三协议，核对源码与产物 token 同一身份、双向混合装配和进程退出。未执行 e2e/main.ts。

资源验证包括单槽背压、预取消、描述阶段及传输/消费者超时、并发过载、实际工作未结束时保留容量、关闭后回调撤销、迭代器持有句柄时释放输入与服务引用。输入快照、封闭错误词表、预算拒绝后的 hasOutput 以及连续事件序号均有症状回归。

[行为矩阵](../plans/BEHAVIOR-MATRIX.md)列明每项取舍与测试位置。独立[切片审查](slice-review.md)的8项问题、[协议审查](protocol-review.md)的6项问题均已复核闭合，审查者只读，实现者负责修改。合法协议输入导致的断言修订及原因已单独记入协议审查；没有删断言或静音测试来迁就实现。

`bun run benchmark:llm`：54个规范化样本、9个真实回环HTTP样本，保留原始样本与环境/源码指纹；该指纹已与原工作目录生产源码重新核对一致。数据量16/64/256KiB，chunk 1/64/4096字节，预热后各3次。普通流累计器不保留完整文本；Responses 尾值核对缓存受输出字节预算约束并在关闭后归零。这是累积缓存观测，不是进程峰值堆内存。见[benchmark.json](benchmark.json)；不据此声称远端模型性能最优或可用性保证。

## 集成与运行边界

原工作目录按任务前SHA256逐路径检查，仅同步本任务文件与必要装配入口；core/session其他在途源码未覆盖。JSONL三处测试store未关闭，经用户明确授权，在finally关闭，全部原断言保留；补丁见[integration-cleanup.patch](integration-cleanup.patch)。专项3例通过，集成后未处理FileHandle异常消失。

core的GC测试固定15轮后检查，独立16次中1次未及时回收。用户明确授权后，测试装置改为最多等待1秒、全部目标回收则提前结束；生产core源码与父测试全部断言保留。实际应用后的专项1文件11例通过，8并发子进程共64次全部回收成功；临时副本故意保留强引用时subjectCollected仍为false，原断言仍会失败。补丁见[integration-gc.patch](integration-gc.patch)，压力与负控制见[integration-gc-verification.json](integration-gc-verification.json)。补丁应用后在原工作目录重新运行四门，131文件1097例通过，覆盖率保持上表数字。此前失败证据保留于本记录，未用静默重试替代修复。

线上厂商检查未执行，未读取用户密钥、未触发付费调用。`bun run test:llm:live`要求显式提供协议、base URL、模型与密钥，仅验证指定配置的文本流；回环测试不冒充线上厂商认证。
