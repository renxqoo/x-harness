# JSONL 验证口径

状态：已核销。

- 先用真实文件写红测：两个独立服务通过公共20项检查；create→append→位置替换→历史/对话分页→fork→关闭重开。
- 输入形状、getter/稀疏数组、UTF-8、记录/批次/namespace/元数据配额、配置冲突、返回冻结及隔离沿公共契约验证。
- 完整但损坏的记录/footer/摘要/头、错误UTF-8、序列空洞、无效投影和重复提交身份明确storage-corrupt，不能清空降级。
- 逐字节截断正常追加的记录/结束标记，恢复仅保留完整提交；未完尾部截断后可继续提交；完整提交丢回执仍可同ID查证/重试。
- 两进程CAS一成功；相同提交两进程共用回执；持锁进程SIGKILL后另一进程取得锁；commit成功后SIGKILL并重开；写到正文/partial footer时SIGKILL不产生半批。
- fork staging或rename前SIGKILL不发布目标、不占配额；rename后未知结果可幂等恢复。保留source seq/time；父回执隔离；来源追加不改变前缀。
- 文件写入短写/写失败/sync失败/rename失败/目录sync失败及打开失败；关闭等待实际工作，锁等待取消及busy，句柄/FFI关闭。
- 同一进程两个实例及不同namespace共享根目录，缓存增量更新、失效/驱逐；不整段载入正文，编码行和索引硬限执行。
- 平台/符号链接/非文件/无标记非空目录拒绝；非法路径和id不能越界。
- 源码与构建入口各运行真实子进程，使用同形态provider，退出码与最终数据一致。
- 六项以上协议负控制：去CAS、忽略指纹、破坏checksum、取消fsync、提前发布fork、吞完整坏行、忽略尾部恢复至少验证关键子集能由指定行为断言检出。
- packages/v2四门；新增源码全部纳入覆盖，阈值90/88/95/96保持。区分另一Agent在途失败，不改其断言。报告实际用例数及四项覆盖率。

- 投影旧节点反复加入/移动触发整理，重开保持全部回执和投影；快照不完整不得当空会话；bootstrap在创建锁、写format、写policy各阶段死亡均能重开，未知rename的幂等路径先sync目录。
