## 行为基线

- [x] 历史连续seq、合法消息、未知业务event、immutable快照及拒绝getter/循环/非普通原型。

## 方案审查反例

- [x] replace后seq非单调视图按position+revision分页，不遗漏节点；非法或过期游标拒绝。
- [x] history未来上界拒绝；空提交拒绝且不会新增回执。
- [x] namespace会话计数跨客户端一致，关键配额配置不一致拒绝，metadata及回执规模有界。
- [x] 页装不下一条时明确失败，无空页死循环；非终页游标严格前进。
- [x] fork分块重放并原子发布，调用超时/取消不发布部分目标；源批次中间分支合法，不继承父commit回执。
- [x] 阴性getCommit不能使同commitId在途写入失效，后续重试仍至多提交一次。
