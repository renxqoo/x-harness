# 存量行为核销

| 现有能力                                                  | 裁决与依据                                                                                                     |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| tools list/get、schema、输出与 progress 预算              | 保留，原断言保留                                                                                               |
| 直接 execute 满额 busy                                    | 保留；增加共享资源冲突 busy                                                                                    |
| toolAccess required/allow 与 deny wins                    | 保留；业务扩展以执行计划 guard 追加限制                                                                        |
| scheduler 有界排队、优先级轮转、防饥饿、DAG、失败阻断后继 | 保留；就绪后准备与许可检查不占运行名额                                                                         |
| tools 安装快照与执行完成前不释放容量                      | 保留并覆盖资源锁                                                                                               |
| scheduler 排队名称晚绑定                                  | 保留名称语义：旧计划失效后在有执行机会时完整重新准备；直接旧计划失败，不能复用授权/资源；原 lifecycle 断言保留 |
| scheduler 原始发起者不可见                                | 通过 core 通用 initiator 元数据补足；origin 始终保持真实直接委托者                                             |
| 老执行环境 kind/root/fs/spawn                             | 保留命令执行及真实完成语义；文件系统业务 API 由具体插件实现，不引入工具系统                                    |
| 老沙箱共享网络配置与自动非沙箱重试                        | 不引入；每次独立配置，失败不得扩大权限                                                                         |
| 老工具类型 Read/Write/Danger 与固定 permission 模式       | 不引入；命名空间 actions 和用户权限插件表达策略                                                                |
| 宿主审批/LLM 判断                                         | 用户裁决：不内置业务实现；提供异步权限扩展、单次计划和可撤销许可                                               |
