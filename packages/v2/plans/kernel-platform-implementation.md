# 通用插件平台施工图

状态：已实现并核销，验收见 [平台验收记录](../reviews/kernel-platform.md)。

1. 生命周期纵切：Owner 只读视图、Lifetime 状态转换；Registry 提供者构造/集合变更；资源钩子在登记参数中完成。执行活动集合移入 Execution，依赖集合移入 Registry，资源集合保留 Lifetime。静态门禁禁止跨层可变状态。现有公开入口和回归保持。
2. 标准插件：standard/src 的 logger、timer、config；共享边界校验与 JSON 快照；同目录测试、独立文档及类型例。
3. 自动装配：application/src 期望集合、安全依赖排序、消费者重装、失败/待定状态、关闭收敛与预算；在纯平台接口上先验收。
4. loader/HMR：Bun adapter、安全构建/导入、稳定 shared 身份、真实监听、变更合并、关闭及缓存预算。实现对照当前 Bun 类型与官方文档，不假设运行时有模块卸载能力。
5. create：可独立调用的生成函数和CLI，排他目录和文件创建、目录身份校验、失败保留未完成目录，以及真实生成工程旅程。
6. 整体验收：全部包纳入四门和覆盖率，独立对抗审查、故障注入、目标功能e2e、原目录同步与最终四门。

所有阶段共用设计基线。最小生命周期纵切先走完整验证与独立审查，发现规格问题先同步文档再继续。实现同一事实只保留一条路径，不保留旧内部工厂或入口别名。审查者不修改实现。不会执行 push/publish，不把他人改动纳入提交。
