# 通用插件平台设计基线

状态：已实现并核销，验收见 [平台验收记录](../reviews/kernel-platform.md)。级别：大。范围：packages/v2。用户裁决：完成生命周期状态统一管理、logger/timer/config 标准插件、插件脚手架，并完成后续自动重新装配及 loader/HMR。保留现有作者 API 命名及 Result.error，不保留兼容层，不增加代码注释。

## 现状与不变量

内核已有原子安装、固定依赖、保护/级联卸载、范围隔离、真实工作与对外结果分离、资源迟到回收和结构化诊断。基线为 357 个运行测试、55 类型负例、24 文档示例；原有覆盖率门槛语句90/分支88/函数95/行96保持不变。目录外已有他人暂存改动，本轮不改动。

Owner/Provider/Effect 目前被多个模块直接写入。重构后这些类型是只读视图，修改数据只存在于所属模块的私有闭包；命令必须表达实际状态操作。Lifetime 管 Owner 状态、子范围、撤销和 Effect 清理；Registry 管绑定、提供者、登记、租约、pins；Execution 管拥有者活动工作。模块读取只读集合，不能通过公开可写记录同步内部状态。Scope 自身的停止与关闭继续由 Lifetime 管理。装配事务由 Assembly 管理。

## 组件边界

core：通用依赖、范围、生命周期、资源、受管执行及协作机制。standard：平台无关的 logger/timer/config 服务与作者辅助函数。core/validation子入口复用现有安全对象读取、JSON快照、Result归一及错误构造，外围不得复制内核输入协议校验。application：平台无关的声明式插件集合及自动重新装配。loader：Bun 的模块构建/导入、文件监听与 HMR。create：Bun 文件脚手架 CLI。外围只导入 core 公开入口，core 不反向依赖外围或平台 I/O。

## 标准插件契约

logger 提供结构化级别日志，输入为 message 和可选 JSON 字段，输出通过显式 sink；级别过滤、不可变快照和异常转 Result 由插件完成，禁止保留原始输入和异常。sink 不自动重试；并发与期限遵守受管服务调用。

timer 提供遵守调用期限的受取消 sleep 服务，以及绑定插件Context的定时辅助入口。周期执行由插件资源持有调度器，每次触发创建一个有限受管任务；TaskHandle增加finished Promise，表示包括子工作在内的实际结算；受管调用内部仍用call.wait维护等待图，finished供宿主和生命周期适配器排空。等待finished后再排下一次，不能使用永久startTask+sleep循环。取消或失败后停止续调，关闭中取消定时器和当前任务并等待实际函数结束。定时器在完成、取消、卸载时移除，实际函数未结束不释放工作预算。计时器调度器可注入；默认只使用标准计时器，不依赖文件系统。

config 为 JSON 配置提供 schema 校验、不可变读取、单调修订和显式管理写入口。读写权限通过不同 token 表达；无效更新不改变当前配置。配置变更事件只在可提交时接受，插件重装与业务恢复由 application 决策。可复用插件定义的各安装实例必须有独立配置状态。

## 应用装配契约

createApplication 创建独占插件装配权的宿主门面。setPlugins 提交以 Plugin.name 为唯一标识的完整期望集合，操作串行且有容量上界。缺失必需依赖的条目保持 pending；提供者出现后激活。提供者移除或实例改变时，先停止并排空传递消费者，再替换提供者并重新激活消费者；可选依赖的出现/消失同样重新装配，旧服务门面不会转向新实例。保留原始 Plugin 声明作为期望状态，不修改 core 固定绑定语义。

配置可以通过构造带新配置的插件定义后提交 setPlugins 更新。快照报告每个条目的 active/pending/failed 状态与受限错误。失败清理、实际未排空或宿主关闭必须阻止替换；refresh 可在真实收敛后重试。独立条目失败不能伪造全部激活成功。期望状态与当前实例状态分开表达；无效输入在停止旧实例前拒绝。core公开无副作用的validatePlugin，并与planLoad共用真实token身份及声明校验；application不能复制半套校验或试装。应用关闭立即阻止新操作并取消宿主工作。

## 模块加载与 HMR 契约

loader 在发布前构建并导入插件模块，模块默认导出 Plugin。core 及配置的 shared 契约模块使用稳定导入身份，不进入重新构建的私有模块副本。构建/导入失败保留当前已运行插件集合；每个条目导入成功即更新准备缓存，后续条目失败也不丢弃已准备定义；全部条目成功才发布整个集合。导入缓存保存已经准备的定义，激活或清理暂未收敛时重试同一产物不重新导入、不消耗额外缓存预算；初始化失败且关闭未收敛时返回restart-required，不能隐藏无法安全结束的初始宿主。有效模块通过 application 重新装配。文件变化合并为有界重载请求，close 先关闭监听和延迟回调再关闭应用。

JavaScript 模块缓存无法强制卸载。模块导入使用进程级有界预算，预算耗尽、shared 契约变化或不能安全替换时返回 restart-required，由外部进程监督执行重启。强制单文件、不拆chunk；只允许core/标准插件公共入口、shared契约和平台内置模块作为external，其他依赖打包；剩余动态导入不属于支持范围，使用Acorn解析构建产物核对外部静态导入及ImportExpression；源码中的静态动态导入只有已被完整打包消除时允许。预算在import前预留，失败导入也消耗预算。shared按配置的源目录边界保持稳定，目录内任意改动均要求重启，避免遗漏传递依赖。顶层模块代码仅接受可信且无未登记副作用的模块；默认导入期限5秒，顶层await超期消耗预算并要求进程重启，不能强行停止JavaScript模块执行。单模块构建产物设大小上限；构建临时文件始终清除。HMR 不宣称请求零中断，不实现进程监督、分布式故障恢复或持久消息投递。

## 脚手架契约

create CLI 生成可运行的 TypeScript 插件工程：契约、插件、启动入口、测试、package.json、tsconfig 和当前行为说明。名称/目标目录先校验；目录已存在或存在符号链接冲突时拒绝，不能覆盖用户文件。依赖采用显式本地路径或发布包名，不自动安装、不访问网络、不发布。目标目录采用排他mkdir创建，生成期间目录可见，入口与完成标志最后写入；不承诺整个目录原子可见。文件使用排他创建。文件系统的身份检查与unlink不是原子操作，不能兑现并发替换下的安全回滚；生成失败时保留未完成目标目录并在错误中返回目录，绝不自动unlink/rmdir。完成标志.ready最后写入且核验目录身份；调用者必须以ok结果判定成功，完成标志只用于辅助检查。此裁决根治独立审查复现的检查后误删用户文件竞态。真实子进程验证生成工程可编译、构建、运行测试并正确关闭资源。

## 并发与容量

装配与模块变更使用有界串行队列；文件变化最多保留一个后续刷新标记。导入预算通过不可替换的进程全局Symbol端口共享，源码与构建副本不能各自计数；仅支持完整打包消除的require，import.meta仅接受直接url/main读取，拒绝解构、反射、动态属性和其他能力；剩余import.meta.require能力及计算式require、未允许的静态require同样拒绝。文件发现阶段即收集监听目录，构建失败仍更新监听，入口及shared目录递归监听，新增目录监听后再验证一次以覆盖安装监听前的修复；同步监听前剔除已删除的私有目录，入口目录缺失时监听最近现存祖先，避免合法删除依赖永久阻塞重载。默认应用条目上限128、排队操作上限32；模块导入进程预算64，单产物上限1MiB。shared最多32项，目录快照最多1024项、单文件1MiB、总16MiB，拒绝符号链接；最多512个私有依赖目录监听。默认日志字段与配置快照遵守JSON的64KiB/32层/10000节点限制。插件资源及工作继续遵守core限额。具体可注入选项以各单元接口为准，同一默认值只在一处定义。

派生作者Context与deps门面统一登记到原始能力的撤销链，实际结算/卸载后清空token、声明、已取得门面及上下文引用；不能以每个定时工具增加宿主监听来代替能力撤销。历史快照不能保留上下文、token、连接或原始异常；期望插件定义仅在注册期间保留。关闭后清理外部监听、计时器、临时文件和不再需要的插件定义。业务代码直接创建的未登记副作用仍由插件负责。
