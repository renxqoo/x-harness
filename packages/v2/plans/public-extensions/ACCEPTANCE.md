# 普通插件扩展契约验收

## 交付

权限通过公开 `toolExecutionAccess` 与 `ToolAuthorization.allow` 授予，授予者生命周期、外部撤销、同步有效性判断均参与提交检查。默认受控模式不接受无策略或只有裸 allow 的执行。

工具可由普通 `definePlugin` 通过公开 `toolCatalog`、`toolPreparation`、`toolDispatch` 贡献。工厂只调用同一公开契约。输入输出校验、期限、进度、并发和实际退出等待集中在 tools 边界。私有 internal 入口、目录品牌与专用策略登记表已删除。

安装身份按原生 signal 与工具名固定，等值新对象不能绕过并发；同一安装的描述冲突拒绝；每个生命周期最多 128 个名称，卸载清空。请求保留原对象验证，复制请求不能更换已批准输入。公开文档中的普通权限、普通工具及其他服务扩展方式均通过类型验证。

LLM provider、session storage、execution 后端已经能直接通过公开服务契约接入；本轮不改它们的业务实现，补充 LLM 接入说明。core 没有新增业务功能。

## 验证

隔离工作区与合入后的主工作区四门全部通过：lint 0 error / 0 warning，typecheck 通过，build 通过，174 个测试文件共 1555 个测试通过。相对基线新增 28 个用例，原测试断言保留；只有受控策略装置及私有入口引用按公开契约适配。

主工作区最终覆盖率：语句 91.36%（9297/10176），分支 90.09%（7935/8807），函数 97.77%（1407/1439），行 98.44%（4318/4386）。阈值保持 90/88/95/96。类型检查拒绝 170 个反例，并通过 39 个文档示例。

tools 专项 200 个用例；17 个故意破坏实现的变异全部被行为断言检出，包括许可绕过、迟到授权、撤销监听泄漏、普通工具容量提前释放、全新目录对象绕过并发及 Unicode 等值声明误判。执行链专项 96 个用例；10 个变异全部检出。报告见 [tools mutations](../../plugins/tools/reviews/mutations.json) 与 [execution mutations](../../reviews/tool-execution/mutations.json)。没有使用跳过、删除断言或降阈值规避失败。

复用跨进程源码/构建混合装置，覆盖普通插件与便利工厂两种接入方式，真实贯通权限、调度、工具及 macOS SRT 进程，验证拒绝与依赖失败传播、输出及实际工作排空。

本地 tools 基准 30 个样本，协调与进程基准 15 个样本，报告见 [tools benchmark](../../plugins/tools/reviews/benchmark.json) 与 [execution benchmark](../../reviews/tool-execution/benchmark.json)。断言读取并行峰值 8、冲突写入峰值 1。样本只说明本机观察，不作跨框架性能或分布式可用性结论。

## 独立审查

只读审查实证两个问题并复测修复：

- P1：普通作者每次目录查询返回全新对象时，内部身份变化使并发失效。改用生命周期与工具名建立有界索引，原探针复测一次执行、第二次 busy。
- P2：使用本地化字符串排序导致等值 Unicode 字段逆序后误判冲突。签名改用严格码元总序，逆序回归通过。

额外 WeakRef 探针确认编译缓存随所有者取消可被回收；保存授权与目录回调的 GC 专项通过。最终只读审查没有未修复的可复现发现。

## 使用边界

普通插件仍是受信任的应用代码；公开契约不隔离任意宿主 JavaScript。宿主提供交互、身份认证和业务策略。取消回执不等于实际函数结束，不合作代码在退出前继续占用容量与资源。源码/构建混合部署需保留完整包布局，不能只复制 dist。
