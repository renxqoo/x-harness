# 插件诊断方案

状态：已核销。级别：中。

## 契约

Host.inspect() 返回冻结的纯数据快照。plugins 增加 dependencies（本地名称、定义名称与种类、是否可选、固定提供者）和 provides。work 列出实际未结束的调用与任务，包含 id、kind、label（任务标签、服务方法或扩展点名称）、phase、executor、resourceOwner、parentId、cancelled、bodyComplete、waitingFor；resources 列出尚未释放的资源，包含 id、kind、owner、executor、state 和固定清理依赖。work、resources 分别替代只能列 ID 的 remainingTasks、remainingEffects，不保留别名。聚合计数仍用于容量检查。

错误继续使用 Result.error。missing-dependency 指出缺失定义；plugin-in-use 指出第一个确定的阻塞提供者和相关消费者、资源、工作；close-incomplete 指出关闭目标及实际剩余工作、资源。错误和对应 Diagnostic 共享同一份冻结详情，顶层 scopeId、pluginName 一致。diagnostics/onDiagnostic 保持有界及重入隔离。

不记录业务参数、返回值、连接对象、函数和原始异常。提供者只输出复制的 id、定义元数据及拥有者标识；不暴露 token 或内部对象。可选依赖缺席显示 null，不能伪造依赖。快照不会触发服务方法或推进生命周期。

## 问题域

处理依赖关系、资源归属、关闭阻塞与诊断一致性。资源种类由登记路径产生（cleanup、resource、provider、registration），不增加插件作者 API。保留用户已经选定的 use、call.effect、call.spawn 等命名。自动恢复、模块重载由外部装配器承担，日志输出、图形面板由宿主承担。

## 并发与一致性预算

快照同步读取当前账本，不新增定时器、订阅和长期索引。复杂度为所输出条目与依赖边数量的线性量级，数据上界继承现有限额。诊断中的每个列表最多采样 8 条，报告 total 与 omitted；关闭摘要只复制必要身份字段，避免完整依赖图放大。工作摘要 label 最多保留 160 个 UTF-16 代码单元，截断时标记 labelTruncated: true；完整工作快照保留原始标签。服务方法名不假设与任务标签具有相同长度上限。JSON 详情遵守现有 65536 字节、10000 节点、32 层限制。持久诊断不能保留 Owner、Work、Effect、Provider 或 DefinitionRef。已返回的快照不会随实际结算改变。迟到成功不能为同一次关闭追加第二条超时诊断。

## 拆分

foundation 提供纯元数据快照函数与诊断复制边界；execution 保存已经验证的任务 label，提供等待目标的只读查询；lifetime 通过资源与现有 CleanupControl.works 的临时只读关联精确定位手动清理工作，结束后撤销关联；输出资源快照及关闭摘要；assembly 在缺失依赖、卸载保护处附带定位信息；context 组合 inspect。保持现有运行时依赖方向与私有账本。

## 实施顺序

1. 先锁定公开类型与行为测试：缺依赖、可选缺席、固定绑定、任务标签/父子等待、资源归属、快照冻结及敏感值隔离。
2. 实现纯快照及错误定位，统一范围关闭、插件卸载、手动资源关闭的失败详情；保留实际执行与对外回执分离。
3. 同步文档、运行四门及覆盖率，独立审查生命周期与敏感引用，核销问题并再次验证。无兼容过渡接口。

## 裁决

用户裁决：继续推进此前建议的诊断能力，保持通用插件内核与简单作者接口。默认实现：结构化快照属于宿主接口，插件不增加诊断权限；诊断列表采样，inspect 提供受容量限制的完整图。

## 测试口径

- 缺依赖未执行 setup，错误指出插件/服务；错误与诊断字段一致。
- requires/optional 的固定绑定、祖先提供、兄弟 shadow、同名插件的实例身份可区分。
- 普通消费者、资源 pin、宿主消费者均能定位卸载阻塞，失败不停止目标。
- 任务 label、父子关系、显式等待、取消但未实际结束、迟到收敛可观察。
- cleanup/resource/provider/registration 的状态和拥有者正确；失败保留，成功移除。
- 根/子范围关闭、级联卸载、手动 disposer 超时可定位；快照只包括相关目标，不混入兄弟。
- 0 条及超出 8 条时 total/omitted 正确；超长合法标签、多字节名称可正常序列化；历史快照深冻结。
- 恶意 token 描述器不执行，sink 抛错与重入不污染回执，业务秘密不进入快照。
- 所有受控挂起工作最后结算，既有引用释放测试全部回归；门禁保持现有阈值。
