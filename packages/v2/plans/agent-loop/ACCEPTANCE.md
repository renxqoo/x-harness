| 取消/消费者异常回执等待不合作函数退出    | core cancelled/timeout 提前结算，实际排空后释放名额；provider/tool gate 回归 |

消费者回执断言调整有明确契约原因：public core 的业务返回必须等待子任务实际排空，只有 cancel 能提前结算且返回 CoreFault。故 callback 抛错改为 cancelled，consumer 超时仍 timeout；保留无后续副作用、容量保持与秘密不泄露的断言，没有删除、skip 或降低覆盖率。

## 部署边界

一次 run 是本进程的执行尝试，runId 不是跨节点互斥锁。检查点 CAS 不等于分布式执行租约；持久化插件必须显式装配。远端工具失败与取消都可能有副作用，缺结果时由宿主对账，不能盲目重放。JS 插件属于受信任代码，取消不强杀任意不合作函数。以上是公开边界，不提供 exactly-once 或分布式故障切换承诺。
